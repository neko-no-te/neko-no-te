# 9個め「請求書つくり機」（約20分）

表の「請求の一覧」に1行（取引先・内容・金額・税率・期日）を書くと、請求書の PDF がドライブの月のフォルダにでき、その行に請求番号・PDF のリンク・作った日時が入り、Gmail の「下書き」に PDF の付いた相手あてのメールができます。**送るのは人です**（この道具は、メールを送りません）。

- **1個め〜8個めは要りません**。LINE も AI も使いません。Google のアカウントが1つあれば動きます
- 先月の請求書をコピーして作りません。作るたびに、名前の入っていない空のひな形を写して、宛名・住所・メールの宛先を「取引先」のシートから引いて差しこみます（前の請求書の字が残る所がありません）。**「取引先」のシートの中身が間違っていれば、間違ったまま出ます**
- お金はかかりません（Google の無料の範囲で動きます）

| ファイル | 何か |
|---|---|
| Seikyu.gs | プログラム。新しいスクリプトにまるごと貼る |
| appsscript.json | 設定のファイル。求める許可を決めます（これも貼る） |

**大事なこと**

- 見本です。自分の会社で使う前に、自分のアカウントで試して、動きを確かめてください。使ったことで起きたことの責任は負えません（LICENSE のとおり）
- **1個め〜8個めとは別の、新しいスクリプトに入れてください**（同じスクリプトに混ぜない）。スクリプトは、だれとも共有しない
- **インボイス（適格請求書）の形が自分の会社に合っているか・送った PDF の控えの残し方は、税理士に確かめてください**。この道具は、国税庁が挙げている6つの項目（発行者の名前と登録番号・取引の日・内容・税率ごとの額と税率・税率ごとの消費税・相手の名前）の欄を用意していますが、「これで足りる」とは言い切れません
- 取引先の担当の人の名前とメールアドレスが、表に入ります。表を共有する相手は、請求を作る人だけにしてください

## 入れ方

### 1. スクリプトを作って、プログラムを貼る

1. https://script.google.com で「新しいプロジェクト」。名前は「請求書つくり機」（だれとも共有しない）
2. 最初からある中身を消して、Seikyu.gs の中身をまるごと貼り、保存する
3. 左の歯車「プロジェクトの設定」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」に印を付ける
4. 左の「エディタ」に戻ると、ファイルの一覧に appsscript.json が出る → 開いて、中身を全部消し、この置き場の appsscript.json の中身をまるごと貼って、保存する

### 2. 準備のプログラムを1回動かす

1. 動かす関数に `setupSeikyu` を選んで「実行」
2. 「承認が必要です」→「権限を確認」→ 自分のアカウント →（「詳細」→「…に移動」）→「許可」
3. 下の「実行ログ」に、表とフォルダの住所が出る → 表を開く

setupSeikyu がやること: 表「請求書つくり機」（「取引先」「請求の一覧」「請求書_ひな形」「設定」の4枚）と、作業用の表「請求書つくり機（作業用・共有しない）」と、ドライブの「請求書」のフォルダを作る／「設定」と「請求書_ひな形」に、持ち主だけが書き換えられる保護をかける／10分おきの自動実行と、「今すぐ作る」の箱のための自動実行を置く。何回動かしても、表やフォルダは増えません（自分で直したひな形と、設定の値は残ります）。

- **作業用の表は、共有しないでください・消さないでください**。請求書は、ひな形をこの表に写して作ります（請求の一覧の表を共有した人が、作りかけの請求書に触れないようにするためです）。共有されているのを見つけると、作らずに止まります
- 登録番号が空のあいだは、請求書に登録番号を出しません（適格請求書〈インボイス〉の形になりません）。準備の記録にも、そう出ます

### 許可する内容

| 許可 | 何に使うか |
|---|---|
| Google スプレッドシートの表示・編集・作成・削除 | 表を作る・請求の一覧を読んで書く |
| Google ドライブのファイルの表示・編集・作成・削除 | 「請求書」のフォルダと PDF を作る・作り直す前の PDF を移す |
| 外部サービスへの接続 | 自分の表を PDF で書き出す Google の住所を呼ぶ（ほかの所は呼びません） |
| 自動実行（トリガー）の管理 | 10分おきと「今すぐ作る」の箱 |
| Gmail の下書きの管理とメールの送信 | 下書きを作る・作り直すときに前の下書きを消す。**Google には「下書きだけ」の許可が無いので、許可の名前に「送信」が入りますが、このプログラムにはメールを送る命令がありません**。メールを読む・消す許可は求めません |

- スクリプトは、このアカウントのドライブとスプレッドシートを全部扱える許可を持ちます。**会社用に、この道具のためだけの Google アカウントを作って入れる**のが安全です（下書きは、そのアカウントの Gmail にできます）
- 下書きが要らないときは、表の「設定」の「メールの下書き」を「作らない」にします（許可は求められたままです）。許可も求めたくないときは、appsscript.json の代わりに、次の中身を貼ってから、「設定」を「作らない」にしてください

```json
{
  "timeZone": "Asia/Tokyo",
  "runtimeVersion": "V8",
  "exceptionLogging": "STACKDRIVER",
  "oauthScopes": [
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/script.scriptapp"
  ]
}
```

### 3. 「設定」と「取引先」を入れる

1. 「設定」のシートに、自分の会社の名前（必ず）・郵便番号と住所・電話・登録番号（T と13けたの数字。登録していなければ空のまま）・お振込先を入れる
2. 「取引先」のシートに、相手を1行ずつ入れる: 取引先（名前）・敬称（「御中」か「様」。空なら「御中」）・郵便番号・住所・担当・メール（下書きの宛先。空なら PDF だけ作ります）

### 4. 試す

1. 「請求の一覧」の3行めに、取引先（選ぶ）・内容・金額（税抜）・税率（10% か 8%）・期日を入れる
2. 1行めの「今すぐ作る」の箱に印を付ける（付けなくても、10分おきにひとりでに作ります）
3. その行に、請求番号・消費税・合計・PDF のリンク・作った日時・「下書きあり」が入る（箱の印はひとりでに外れ、1行めの右のほうに「1通作りました（日時）」と出ます）
4. PDF のリンクを開いて、請求書を見る。Gmail の「下書き」を開いて、宛先・宛名・添付を見る

## 請求の一覧の見方

| 列 | 入れる人 | 中身 |
|---|---|---|
| 取引先・内容・金額（税抜）・税率・期日 | 人（必ず） | 5つがそろうまでは、作らずに待ちます。金額は税抜（3,000円・10% なら、消費税 300円・合計 3,300円） |
| 請求日 | 人（空でもよい） | 空なら、作った日が入ります |
| 取引日 | 人（空でもよい） | 空なら、請求書には請求日を書きます（「11月分」のように文でもよい） |
| 備考 | 人（空でもよい） | 請求書の備考に出ます |
| 請求番号 | スクリプト | 請求日の年月＋連番（例 202612-001）。**自分で入れないでください**。消した行の番号も、二度使いません。作ったあとの行の番号を消すと、新しい番号でもう1通作ります（前の PDF と下書きは残ります） |
| 消費税・合計（税込）・PDF・作った日時・下書き | スクリプト | |
| 気になる所 | スクリプト | 作らなかった理由（「取引先の表に無い名前です」など）。直すと、次の回に作って消えます |
| やり直し | 人 | 印を付けると、同じ番号で作り直します（下の「作り直すとき」）。チェックの箱は、請求番号が入った行にだけ出ます |

- 1行＝請求書1枚で、内訳は1行・税率は1つです。内訳が何行もある請求書・8%と10%が混ざる請求書は作れません
- **行をコピーして次の請求を作るときは、請求番号から右の列（請求番号・消費税・合計・PDF・作った日時・下書き・気になる所・やり直し）を消してください**。消すと、新しい番号で作ります。消さないと、どちらも作り直しません（同じ番号で、中身の違う請求書を作らないため）。「気になる所」に、元の行には「この行は元の行です」、コピーした行には「この行はコピーした行です。この行の請求番号から右の列を消してください」と出ます。**消すのは、コピーした行のほうです**（元の行の番号を消すと、元の請求書が新しい番号でもう1通できます）。元の行を作ったあとに直してあって、どちらが元かを道具が見分けられないときは、2行とも「コピーした行のほうの、請求番号から右の列を消してください」と出るので、自分でコピーした行を選んで消してください
- 取引先の名前は、1行で入れてください（マスの中で改行しない）
- 請求書に出る字には、長さの上限があります（取引先60字・敬称6字・郵便番号12字・住所80字・担当40字・内容60字・取引日30字・備考200字）。超えると、切らずに「気になる所」に出して、作りません
- 日付は 2000年〜2100年、金額は1円〜999,999,999円の整数（カンマは3けたごと）だけを通します
- 道具は、相手や内容がまともかを判断しません。欄がそろって、形が合っていれば作ります。**「取引先」のシートに無い名前の行だけは、作りません**（打ち間違えた名前の請求書を作らないため。先に「取引先」に足してください）
- 列は、見出しの名前で探します。列を足す・並べ替えるのは自由ですが、**見出しの名前は変えないでください**
- 1回に作るのは10通まで・4分までです。残りは、次の回（10分後）に作ります

## 作り直すとき

- 作ったあとに行を直しても、PDF は変わりません。「気になる所」に「作ったあとに行が直されています」と出ます
- 作り直すときは、行を直して「やり直し」に印を付けます。同じ番号で PDF と下書きを作り直し、前の PDF は「請求書」の中の「作り直し前」のフォルダへ移します（消しません）。前の下書きは消します
- **前の下書きがもう無い（送った・自分で消した）ときは、作り直しません**（相手に届いた請求書と同じ番号で、中身の違う PDF を作らないため）。送ったあとの直しは、新しい行で作ってください（直した請求書の出し方は、税理士に確かめる）
- 下書きを手で消すと、その行の「やり直し」はできなくなります
- 下書きを作らなかった行（メールが空・「作らない」の設定）は、道具には送ったかどうかが分からないので、送ったあとでも作り直せてしまいます。**PDF を自分で送ったあとは、「やり直し」を使わないでください**
- 前の下書きを消せなかったとき（Gmail の一時の不調）は、新しい下書きを作りません。「下書き」の列に「前の下書きを消せませんでした」と出るので、Gmail の下書きを見てから、もう一度「やり直し」に印を付けます
- 「やり直し」の印が付いたままでも、試すのは3回までです（PDF が作れない・前の下書きを確かめられない、が続くと、印を外して「気になる所」に出します）
- 「やり直し」で出た知らせ（「前の下書きがありません…」など）は、ひとりでには消えません。読み終えたら、「気になる所」のマスを自分で消してかまいません（作り直せたときは、ひとりでに消えます）

## 請求書の形を直すとき

「請求書_ひな形」のシートが、請求書の形です。字の大きさ・罫線・列の幅・並びは、表と同じように直せます（直せるのは持ち主だけです）。

- `{{宛名}}` のような差しこみ口に、その行の中身が入ります。使えるのは: `{{宛名}}` `{{敬称}}` `{{宛先の住所}}` `{{担当}}` `{{請求番号}}` `{{請求日}}` `{{期日}}` `{{取引日}}` `{{内容}}` `{{税率}}` `{{金額}}` `{{消費税}}` `{{合計}}` `{{自社の名前}}` `{{自社の住所}}` `{{自社の電話}}` `{{登録番号}}` `{{振込先}}` `{{軽減の注記}}` `{{備考}}` `{{下の一言}}`
- **ひな形には、取引先の名前・金額・日付をじかに書かないでください**。ひな形にじかに書いた字は、全部の請求書に出ます。取引先の名前が書かれているのを見つけると、どの行も作らずに止まります
- 宛名・敬称・請求番号・請求日・期日・取引日・内容・税率・金額・消費税・合計・軽減の注記の差しこみ口を消すと、作らずに止まります（「御中」をじかに書かず、`{{敬称}}` のままにしておく）
- ひな形を最初の形に戻したいときは、「請求書_ひな形」のシートを消して、すぐに `setupSeikyu` をもう一度動かします
- `setupSeikyu` は、自分が作って保護をかけた「設定」「請求書_ひな形」だけを使います。覚えのない同じ名前のシートがあったときは、使わずに「設定（前のもの・確かめる …）」のように名前を替えて残し、新しいシートを作ります。**中身を自分の目で確かめてから、要る所だけ写してください**

## 守り

- **送る前に、宛先・宛名・添付の PDF の全部（お振込先も）を見てください**。下書きの本文の1行めに宛名が出ます
- 表を「編集者」で共有した人は、取引先の名前・住所・担当・メールアドレスや、内容・金額・備考を書き換えられます（請求を作る人の仕事なので、止めていません）。**書いた字は、そのまま請求書に出ます**（備考や住所に「お振込先が変わりました」と書けば、そう出ます）
- **お振込先・発行者の名前・登録番号・請求書の形の欄は、持ち主だけが書き換えられます**（「設定」と「請求書_ひな形」の保護）。保護が外れている・ゆるんでいるのを見つけると、作らずに止まります。そのときは、**先に「設定」の値（とくにお振込先）とひな形の字が書き換えられていないかを見てから**、`setupSeikyu` を動かし直してください
- 請求書は、だれとも共有しない作業用の表で作ります。請求の一覧の表を共有した人は、作りかけの請求書に触れません
- 「請求書」のフォルダは、共有なしで作ります。共有する相手は、請求を作る人だけにしてください
- 取引先の名前・金額・メールアドレスは、スクリプトの記録に出しません（出すのは件数だけ）

## 止まったとき

止まると、Google から持ち主にメールが届きます（「今すぐ作る」の箱で動かしたときは、箱の右にも出ます）。

| 出る文 | すること |
|---|---|
| 「設定」のシートの「◯◯」を確かめてください | その項目を直す（自社の名前が空・登録番号の形・消費税の端数など） |
| 「設定」／「請求書_ひな形」のシートの保護が外れているか、ゆるんでいます | 「設定」の値（とくにお振込先）とひな形の字を、自分の目で確かめてから、`setupSeikyu` をもう一度動かす |
| 作業用の表が、ほかの人と共有されています／見つかりません | 作業用の表の共有を外す／`setupSeikyu` をもう一度動かす（作り直します） |
| ひな形に、取引先の名前が書かれています | 「請求書_ひな形」から、その名前を消す |
| ひな形に、差しこみ口がありません／知らない差しこみ口があります | 差しこみ口を直す（上の一覧のとおりに） |
| 請求書の PDF を入れるフォルダが見つかりません | `setupSeikyu` をもう一度動かす（新しいフォルダを作ります） |
| 請求の一覧に書けませんでした | 行やシートに保護・入力の決まりを付けていないかを見る。書けない行は、PDF を作りません |
| 請求書を PDF で書き出せません | `setupSeikyu` をもう一度動かして、許可をやり直す |

- 混んでいて PDF が作れなかった行は、次の回にもう一度作ります（3回まで。だめなら「気になる所」に出るので、「やり直し」に印を付けます）
- 10分おきの自動実行は、作る行が無い回も動きます。表を書き換えるたびにも、「今すぐ作る」の箱かどうかを見る自動実行が短く動きます。無料のアカウントの自動実行は、ほかの道具と合わせて1日90分までです

## データの置き場・やめるとき

- 請求書の PDF はドライブの「請求書」のフォルダに、一覧と取引先は表に、自分で消すまで残ります
- 作った記録（請求番号ごとに、PDF と下書きの番号）を、スクリプトの「スクリプト プロパティ」（表を共有した人には見えない所）に持ちます。1通でおよそ180バイト、置き場は全部で500KBなので、**およそ2,500通**でいっぱいになります。いっぱいになると、新しい請求書を作る所で止まります（何も作りません）。そのときは、スクリプト プロパティから、古い年の `SEIKYU_INV_` で始まる項目を消してください（消した番号の行は、「やり直し」ができなくなります）
- やめるとき: スクリプトの左の目覚まし時計「トリガー」で、自動実行（makeInvoices・onSeikyuEdit）を消す。Gmail の許可も外すときは、Google アカウントの「セキュリティ」→「お使いのアカウントにアクセスできるサードパーティ アプリ」から、このスクリプトを外す。表と PDF は残ります。作業用の表「請求書つくり機（作業用・共有しない）」は、要らなければゴミ箱へ（中に請求書は残っていません）
